# Sumanth Photography — Supabase Backend & Database Setup Guide

This directory contains the database schema and migration scripts for Sumanth Photography's backend.

## Architecture Highlights
- **Tables**: `profiles`, `contact_submissions`, `quote_submissions`, `quote_events`, `quote_line_items`, `quote_addons`, `quote_preferences`.
- **Row Level Security (RLS)**:
  - Public anonymous users can only **INSERT** new contact and quote enquiries.
  - Public anonymous users **cannot SELECT, UPDATE, or DELETE** any submissions.
  - Only authenticated admin users with `role = 'admin'` in `public.profiles` can view and manage enquiries.
- **Pricing Snapshotting**: Preserves unit prices, quantities, and discounts exactly as calculated when submitted.
- **Stored Procedure**: `public.submit_full_quote` provides atomic transaction insertion across all quote tables.
- **Default timestamps**: `created_at` and `updated_at` are generated by the database, not the browser.
- **Default status**: New contacts get `status = 'NEW'`, new quotes get `status = 'NEW'` — enforced by database defaults.

## Setup Instructions

### 1. Create a Supabase Project
1. Go to [supabase.com](https://supabase.com) and create a new project (e.g. `sumanth-photography`).
2. Copy your **Project URL** and **Anon Public API Key** from **Project Settings > API**.

### 2. Run Database Migration
1. Open your Supabase Dashboard.
2. Navigate to the **SQL Editor**.
3. Copy the entire content of [`migrations/20260830_initial_schema.sql`](migrations/20260830_initial_schema.sql).
4. Click **Run**. All tables, constraints, indexes, RLS policies, triggers, and the stored procedure will be created.
5. The migration also **cleans all demo/test data** from tables while preserving the schema.

### 3. Create Admin Account
1. In the Supabase Dashboard, go to **Authentication > Users**.
2. Click **Add User** -> **Create user**.
3. Enter your default admin email: `maneekanta0@gmail.com` and password: `Mani@123!`.
4. The `on_auth_user_created` trigger will automatically create a profile with `role = 'admin'`.
5. Verify in **Table Editor > `profiles`** that the row has `role = 'admin'`. If needed, run:
```sql
UPDATE public.profiles
SET role = 'admin'
WHERE email = 'maneekanta0@gmail.com';
```

### 4. Connect Your Website to Supabase (CRITICAL STEP)

You **MUST** set your real Supabase URL and Anon Key in the website code.

**Option A — Direct in HTML** (easiest):

Add this script tag **BEFORE** `<script src="js/supabase-config.js">` in every HTML page that uses Supabase (`contact.html`, `quote.html`, `admin/login.html`, `admin/index.html`, `admin/contacts.html`, `admin/quotes.html`):

```html
<script>
  window.SUMANTH_SUPABASE_CONFIG = {
    url: 'https://YOUR_PROJECT_ID.supabase.co',
    anonKey: 'YOUR_SUPABASE_ANON_KEY'
  };
</script>
```

**Option B — Create a config file** (recommended for production):

Create a file `js/supabase-env.js` with:

```javascript
window.SUMANTH_SUPABASE_CONFIG = {
  url: 'https://YOUR_PROJECT_ID.supabase.co',
  anonKey: 'YOUR_SUPABASE_ANON_KEY'
};
```

Then add `<script src="js/supabase-env.js"></script>` before `<script src="js/supabase-config.js"></script>` in your HTML files.

**Option C — Environment variables** (for build systems):

```javascript
window.__ENV_SUPABASE_URL = 'https://YOUR_PROJECT_ID.supabase.co';
window.__ENV_SUPABASE_ANON_KEY = 'YOUR_SUPABASE_ANON_KEY';
```

### 5. Verify Connection

After configuring, open the browser console on any page. You should NOT see:
```
[Supabase] Live credentials pending
```

Instead, `SumanthDB.isLiveConfigured` should return `true`.

## Data Flow

```
CONTACT FORM (public)
  └──> submitContactSubmission()
       └──> INSERT INTO contact_submissions (status='NEW', created_at=NOW())
            └──> Admin fetches via fetchAdminContacts()
                 └──> SELECT * FROM contact_submissions ORDER BY created_at DESC

BUILD YOUR QUOTE (public)
  └──> submitQuoteSubmission()
       └──> submit_full_quote() stored procedure
            ├──> INSERT INTO quote_submissions (with pricing_snapshot JSONB)
            ├──> INSERT INTO quote_events
            ├──> INSERT INTO quote_line_items
            ├──> INSERT INTO quote_addons
            └──> INSERT INTO quote_preferences
                 └──> Admin fetches via fetchAdminQuotes()
                      └──> SELECT * FROM quote_submissions ORDER BY created_at DESC

ADMIN STATUS UPDATE
  └──> updateContactStatus() / updateQuoteStatus()
       └──> UPDATE contact_submissions/quote_submissions SET status=?, updated_at=NOW()

ADMIN INTERNAL NOTES
  └──> updateContactInternalNotes() / updateQuoteInternalNotes()
       └──> UPDATE contact_submissions/quote_submissions SET internal_notes=?, updated_at=NOW()
```

## Troubleshooting

**Admin panel shows 0 records but submissions were made:**
- Check that `window.SUMANTH_SUPABASE_CONFIG` is set with your real Supabase URL and key
- Open browser console and check `SumanthDB.isLiveConfigured` — must be `true`
- Verify in Supabase Dashboard > Table Editor that rows exist in `contact_submissions` / `quote_submissions`

**Contact form submission fails:**
- Check browser console for RLS policy errors
- Ensure `status` is `'NEW'` and `internal_notes` is empty (RLS enforces this on public inserts)

**Admin login fails:**
- Verify the user exists in Supabase Authentication > Users
- Verify the profile row has `role = 'admin'` in the `profiles` table
